# LaViRA 迁移与验收说明

目标是让 Habitat、Go1、G1、Cobot 的 VLN、ObjectNav、EQA 共用一套可独立接入的 LaViRA 核心。外部管理环境，核心通过通用能力完成一次任务；设计契约见 [共享核心设计](lavira-core-design.md)。本文件记录可审核的交付单元和证据范围，具体临时执行记录放在项目专用临时目录。

## 交付单元

### 1. 合并相同的模型客户端

在 `lavira/clients.py` 保存三台机器人的共同实现。旧 `ai_client/vision_client.py` 仅负责取平台配置并委托；核心必须显式接收配置，不导入平台 `config`。增加最小包配置，保证各平台独立环境可以安装共享核心。

使用标准库 `unittest` 和替代 SDK 记录真实客户端发出的请求。分别对 LA、VA、已有 system 消息、重试、token 统计和失败传播与 Git 中原实现做对照。请求消息、参数和返回结构必须相同。验证旧导入入口仍可用，再提交客户端抽取。

Habitat 客户端另作同一职责下的兼容实现，保持 `max_completion_tokens`/`max_tokens`、timeout、额外参数、字符串返回与错误字符串行为；不把机器人客户端直接套上去。

### 2. 建立任务和执行边界

`lavira/runtime.py` 定义任务、进度和结果；通用观测、转向目标与导航反馈在 `navigation_runtime/`，环境执行器不依赖算法包。使用标准库数据类和类型声明；核心根模块不导入平台或重依赖。

用离线运行时检查完整任务调用中的状态独立、取消信号、结束原因以及缺少到达证据时的结果。额外用一个最小替代算法调用同一执行能力，检查环境端不需要 LaViRA 决策对象。先写失败检查，再实现并运行。

### 3. 提取推理和共享高层驱动

将已有 prompt、消息构建、解析和记忆迁到 `lavira/reasoning/`，保留文本和请求次序。将导航、停止、回溯和问答收尾组织到 `lavira/agent.py` 的唯一任务驱动。平台差异是具体兼容策略与参数，不能各有一份完整循环。

先用固定模型响应覆盖三种关键轨迹：普通导航继续、停止前最后接近、历史观测回溯重规划。检查发出的能力调用、推理输入中的历史图和 TODO。失败分支至少覆盖空观测、解析失败、缺失 bbox 和预算耗尽，按原行为验收。

### 4. 接入 Habitat VLN

修改 `sim-code/habitat/vlnce_baselines/agent.py` 和 `ZS_Evaluator_mp.py`，使旧入口组装核心。环境、地图、控制、数据集和指标归外部；可视化由回调承接。环境 reset 不进入核心。

比较原版和新版在固定模型响应、替代环境下的动作序列，包含全景 12 次转动及预算、方向旋转、目标超时、回溯两种配置、楼梯执行提示和停止确认失败计数。真实 Habitat 数据集、渲染或模型服务不可用时，明确标记该层未验证。

### 5. 依次接入 Go1、G1、Cobot VLN

把 `robot/navigation_api.py` 的算法部分迁入共享推理；把 `tasks/vln.py` 的高层循环替换为核心调用。每个平台的组装和执行适配独立提交，保留 CLI、控制器及 TaskFactory 的入口语义。

对照检查 Go1 的三视角与两次采图、G1 的初始 TODO 与后方旋转、Cobot 的七方向和机械臂复位线程次序。核对轨迹安全距离、像素锚点、TODO 更新、模型 STOP/VA STOP 组合，以及执行失败时旧停止规则。替代执行器只记录调用，不连接机器人。

### 6. 接入 ObjectNav 与 EQA

让四端 ObjectNav 进入同一任务驱动，合并 Cobot 重复循环。保留 Habitat 任务专用 prompt 和机器人的原有任务差异。EQA 用同一导航状态加任务收尾；答案进入结果并由原入口保存或评测。

覆盖四个平台 × 三类任务；EQA 检查问题、图像顺序、答案和请求参数。保留旧取消后可能问答的行为，并在结果中区分取消请求与实际执行；增强取消须另行批准。

### 7. 清理重复实现并交付

删除已经切流且被行为对照覆盖的重复高层流程，旧模块只保留需要的兼容入口。补充共享包安装、完整任务调用和替换算法的使用说明；运行最终离线测试、导入检查与 `git diff --check`。

核对每个平台实际入口是否调用核心，而不只测试新类。检查核心中没有平台导入、平台能力没有算法决策类型、入口不再内置另一套 LA/VA 循环。更新 CodeGraph 并记录最终状态。

| 先抽取请求/推理，再切换任务与执行边界 | 先固定行为基线；过渡期重复辅助实现已在 `92dd54d` 清理。 |
| 通用执行数据放在 `navigation_runtime`，暂与核心同一个 wheel 分发 | 环境源码可以迁出且不导入算法；以后若需单独发布运行时，还需调整打包配置。 |
| Habitat 绘图改为回调，图像高度显式注入 | 移除 visualizer 依赖；调用者需要传入正确高度与记录函数。 |
| EQA 错误单列 `answer_error` | 导航结束原因保持原义；调用方必须同时查看答案和问答错误。 |
| Habitat 历史位姿继续保留 CPU 共享引用 | 遵守行为保留要求；冻结历史位置会改变回溯轨迹，需独立决定。 |
| Habitat `step` 沿用旧动作计数，`cycles` 计 LA 航点决策 | 全景仍按 12 步计费；预算可能越过阈值才退出，取消也不表示物理停止。 |
